# Entegre Client 2.4.3

Tek kurulum ZIP’i, Minecraft **26.2**, Java **25** ve Fabric **0.19.5**.
Voxy 0.2.19-beta, Voxy Extra 0.2.6 ve Voxy WorldGen 2.4.3 birlikte bulunur.

[EntegreClient-v2.4.3.zip indir](https://github.com/EntegreVesselam/EntegreClient/releases/download/v2.4.3/EntegreClient-v2.4.3.zip)
ve Prism’de **Add Instance / Kurulum Ekle → Import / İçe Aktar** ile açın.
Prism’de **Entegre Client** adlı tek profil oluşur. Java 25 seçip başlatın.
ZIP’i eski profilin üstüne çıkarmayın; eski profilinizi kişisel dosyalarıyla saklayın.
İlk açılışta güncelleyici bu profilin 26.2 modlarını indirir. Bu yayın için ayrı
26.3 veya onarım ZIP’i seçmeniz gerekmez. İleriki paket güncellemeleri aynı profil
ve minecraft-26.2 kanalı üzerinden gelir.

Varsayılan kayıt hem görünen ad hem gerçek bağlantı adresi olarak
**entegrevesselam.com** kullanır. Fabrika sunucu kaydı ZIP’in içinde de hazırdır.
**entegrevesselam.com** ve **ugurdindar.com** adreslerinin ikisi de marker
bağlama/eşitleme için kabul edilir; açık :25565 ve büyük harf yazımı desteklenir.
Başka alan adları veya farklı portlar bu sunucuya ait sayılmaz.

2.4.2’de düzeltilen Prism bağımlılığı yeni profilde hazırdır; eski oyunu bu
kurulumun içinde sürüm değiştirerek taşımak gerekmez. Haber/etkinlik menüsü,
topluluk fotoğrafları ve özel ana menüdeki Friends düzeltmesi korunur.

Bu Mac’te Voxy OpenGL desteği yetersiz olduğundan gerçek GPU LOD çizimi
ve canlı sunucu LOD akışı doğrulanmadı. Windows’ta gerçek Prism uçtan uca
kullanıcı kabulü henüz yapılmadı. Test ayrıntıları: docs/release-2.4.3.txt.
